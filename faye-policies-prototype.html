Status badge logic
  • Yellow (warning): Quote created, Quote shared — pending conversion, where the advisor's attention belongs.
  • Green (success): Pre-trip, In trip, Post-trip — sold policies, positive feedback that work has paid off.
  • Red (destructive): Cancelled — broken policy, warrants attention.
  • Gray: Draft, Completed, Declined, Expired — neutral states that don't compete for the eye.
  • Quote created: single quote state — the system can't reliably know whether a quote was shared with the client (copying a link or downloading a PDF doesn't confirm delivery), so we don't pretend to track it. The action is always "Purchase".
  • Deadline countdowns: 7-day CFAR window — only shown if the quote actually includes CFAR. 48-hour trip cancellation window — universal, applies to every quote. Copy: "Xd to lock in CFAR" (amber) → "Xh to lock in trip cancellation" (red). Quotes without CFAR and >48h out show no countdown.
  • Add-ons (incl. CFAR) live in the side panel, not in the table — the table shows just the plan name to stay scannable.
Roster (group trip)
  • Expandable parent row aggregates child travelers' policies. Click the chevron to expand.
  • Parent row shows aggregate destination & dates (or "Multiple"), price total, and a status breakdown ("2 paid · 1 shared · 1 to share").
  • Parent checkbox cascades selection to all children. Partial-selection state shows a small dash.
  • 3-dot on the parent has roster-level actions: send group reminder, export CSV, add traveler.
  • Roster sorts to the position of its most urgent child — so a group with a critical-deadline traveler bubbles up.
Side panel (click any row)
  • Click anywhere on a row except an interactive element (checkbox, chevron, action button, 3-dot) to open the drawer.
  • Actions are scoped to row type — Quote: Email quote / Copy link / Download PDF / Duplicate / Delete. Policy: Email policy / Add flights & docs / Download PDF / Duplicate / Download receipt. Roster parent: Add quote / Delete group. Roster child: child's normal actions + "Move out of group".
  • The drawer is also where audit info, modification timeline, and decline/cancellation reasons will live — kept off the table row to keep the index clean.
  • Close via X, Esc, or clicking the scrim.
